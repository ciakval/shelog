3. src/shelog/importer.py (research Pattern 10, D-09):
   - Checks before any write:
     - resolve both paths; refuse `same_database` (equal resolved paths, or `os.path.samefile` when both exist)
     - refuse `source_missing` if the source is not a file
     - open the target with `connect_rw(target, uri=True)` + `migrate`
     - ATTACH `file:<quoted abs source>?mode=ro` AS src. ATTACH comes before `BEGIN IMMEDIATE`, because SQLite cannot attach inside a transaction.
     - check `src.user_version` is between 1 and the highest known migration, and that src has the reading, raw_status and poll_log tables, else `incompatible_schema`
   - In one `BEGIN IMMEDIATE` ... `COMMIT`, with ROLLBACK on any exception, using explicit column lists and never a star select:

SQLite needs the `WHERE true` before an upsert clause on INSERT ... SELECT.

   - The running production poller is safe next to this: one short transaction under busy_timeout, and the poller's in-memory last states self-heal through its existing conflict path (research Pattern 10 point 5).
