3. src/shelog/health.py (new; shared later by the alerts in plan 02-05):
   - Constants: `POLL_STALE_S = 900`, `POLL_DOWN_S = 3600` (equals the poll_failing alert threshold of D-11), and `DEFAULT_SILENCE_S = {"ht_gen1": 54000, "flood_gen1": 54000, "ht_gen3": 9000}` (matches devices.example.toml and docs/shelly-api.md).
   - Frozen dataclass `DeviceFacts(name, last_report_ts: int | None, threshold_s: int, silent: bool, battery: float | None)`.
   - Frozen dataclass `HealthFacts(now, has_polls, first_poll_ts, last_ok_ts, last_error: str | None, auth: str, devices: tuple[DeviceFacts, ...], status: str)`.
   - `collect(con, devices, now) -> HealthFacts` uses only explicit-column SELECTs on poll_log (kind 'shelly'), reading and meta; it never touches the raw-status table and never uses a star select (IN-07):
     - first poll ts: MIN(ts); last ok ts: MAX(ts) WHERE ok = 1; last error: the error of the newest ok = 0 row by id
     - auth: meta `shelly_auth` mapped to `ok`/`rejected`, anything else `unknown`
     - per configured device: MAX(reading.ts) for its id, and the newest non-NULL battery
     - threshold: `max_silence_s`, or `DEFAULT_SILENCE_S[model]`
   - Silence rule (one definition for health and alerts): a device is silent only when the last ok poll is fresh (`last_ok_ts` not None and `now - last_ok_ts <= POLL_STALE_S`) AND `now - (last_report_ts, or first_poll_ts for a device that never reported) > threshold_s`. While polling is stale, silence is unknowable and reported as false.
   - Status rules, in order:
     - no shelly poll_log row: `unknown`
     - auth rejected: `down`
     - with ref = last_ok_ts if present, else first_poll_ts: `now - ref > POLL_DOWN_S` gives `down`
     - last_ok_ts is None or `now - last_ok_ts > POLL_STALE_S` gives `degraded`
     - any device silent: `degraded`
     - otherwise `ok`
   - `public_body(facts) -> dict` is a whitelist: `status`, `last_poll_ok_ts` (int or None), `auth`, `devices` (`{name: {"silent": bool}}` in configuration order), `generated_at` (now). Never ids, error categories, battery or thresholds (D-06).
   - `unknown_body(devices, now)` has the same shape with status/auth `unknown`, last_poll_ok_ts None and every device silent false.
   - `evaluate(con, devices, now) = public_body(collect(...))`.
