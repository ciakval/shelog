<objective>
Make every stored reading trustworthy and every committed fixture safe. Sanitize the real Shelly response into committed fixtures with a deterministic pseudonymizer, and guard them with a structural scan plus a real-id scan. Then finish the parser and dedup rules against those fixtures and against synthetic edge cases.

Purpose: Core Value is "complete and trustworthy" data in a public repo. A wrong timestamp source or a 0 instead of NULL silently corrupts weeks of history; one leaked MAC or SSID in a fixture cannot be taken back.
Output: `sanitize.py` (library + dev CLI), the sanitized live fixture, synthetic case fixtures, and the parse/store rules with table tests.
</objective>

| Shelly response → stored history | Untrusted values become permanent data |

The CLI post-scan aborts on findings. test_fixture_safety has a structural layer (CI) and a real-id layer (owner machine, can be forced with SHELOG_REQUIRE_REAL_ID_SCAN=1). |
