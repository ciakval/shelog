<objective>
Make every stored reading trustworthy and every committed file safe. Sanitize the real Shelly response into committed fixtures with a deterministic pseudonymizer, and guard the repo with three layers: a structural fixture scan, a real-id scan over every tracked file (`.planning/` included), and a configured-key scan over every tracked file. Then finish the parser and dedup rules against those fixtures and against synthetic edge cases.

Purpose: Core Value is "complete and trustworthy" data in a public repo. A wrong timestamp source or a 0 instead of NULL silently corrupts weeks of history; one leaked MAC, SSID, device id or key in any committed file (a planning SUMMARY included) cannot be taken back.
Output: `sanitize.py` (library + dev CLI), the sanitized live fixture, one synthetic case fixture, and the parse/store rules with table tests.
</objective>
