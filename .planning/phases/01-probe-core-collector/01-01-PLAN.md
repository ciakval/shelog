5. `src/shelog/shelly/transport.py` (D-05): follow research Pattern 1.
   - Form bodies use urlencode with the form content type; JSON bodies use `json.dumps` with `application/json`.
   - Build an opener with a redirect handler whose redirect_request returns None, so a 3xx comes back as a response and a key-bearing body is never re-sent.
   - Read at most MAX_BODY + 1 bytes.
   - Convert HTTPError to RawResponse and close it in `finally`.
   - TimeoutError, or a URLError whose `reason` is a TimeoutError, raises TransportError('timeout'). Any other URLError or OSError raises TransportError('network'). Always raise `from None`. The exception message is the category only.
   - Use default TLS verification only.
   - Put `# noqa: S310` on the open call, with a comment saying https is enforced by config and client.
