<objective>
Build, and prove offline, the probe capture matrix that plan 01-07 runs once against the real account. It must answer what the docs leave open: the response shapes and report-time fields per model, whether v2 is usable, how each device reports, and how the cloud fails (wrong key, wrong host, unknown id, missing route). It does all that within the 1 req/s limit, and without the real key ever going to a host other than SHELLY_HOST. Then add the sanitized fixture export.

Purpose: PROBE-01/02/04/05 need real envelopes. Capturing them safely (rate-guarded, dummy key for every wrong-key or wrong-host request, sanitized before anything is committed) needs this code proven against fakes first. The rate-limit envelope is deliberately NOT captured: no live burst (orchestrator decision 2026-10-31); plan 01-04's synthetic fixture covers it.
Output: the probe step matrix and `--save-fixtures` in probe.py, the CLI flags, and tests/test_probe.py.
</objective>
